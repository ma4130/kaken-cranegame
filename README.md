# スマホで クレーンゲーム

投影した画面にクレーンゲームと景品が映り、体験者のスマホがコントローラーになるゲームです。
ビルドなしの HTML / JS だけで動きます（Three.js と Firebase は CDN から読みこみ）。

- スクリーン（投影するPCで開く）: `index.html`
- コントローラー（スマホ。QRコードから開く）: `controller.html?room=XXXX`

## あそびかた

1. PC で `index.html` を開いて投影し、画面をクリック（音が出るようになります。`F` で全画面）。
2. 体験者がスマホで QR コードを読みとり、ニックネームを入れて「さんかする！」。
3. 順番が来るとスマホがコントローラーになります。
   - ① `→` を長おし … クレーンが横に動く。はなすと止まる
   - ② `↑` を長おし … クレーンが奥に動く。はなすと自動でつかみに行く
4. 景品が左手前の「GET!」の穴に落ちたらゲット。スマホにも結果とコレクションが出ます。

- 1人 2回（`index.html?plays=3` のように変えられます）。同時に何人でも並べます。
- 影の輪っか（ピンクのリング）を景品のまんなかに合わせるのがコツ。少しずれると途中で落ちます。
- 金のくま 🏆 はレアで、少しむずかしいです。
- キーボードの `→` と `↑` でも遊べます（スマホなしの確認用）。

## 通信（Firestore）

スクリーンとスマホは Firestore でつながります。Firebase プロジェクトはクレーンゲーム専用の `kaken-cranegame`（設定は `js/firebase-config.js`）。
Firestore のルールは `firestore.rules` と同じものをコンソールで公開しています。
つながらないときは、スクリーンに赤い「つながりません」の表示が出ます。

## テスト用

- `?local` … Firestore を使わず、同じブラウザのタブどうしでつなぐ（`index.html?local` を開き、QRのURLを別タブで開く）
- `?test` … `window.__crane`（`state` / `press(k)` / `release(k, ms)` / `tick(秒)`）が使える
- `?room=ABCD` … 部屋コードを固定する
